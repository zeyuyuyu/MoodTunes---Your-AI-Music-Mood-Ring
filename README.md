# MoodTunes

An engaging web app that analyzes your selfie to detect your mood and creates a personalized music playlist. Take a photo, let our AI detect your emotional state, and get instant music recommendations that match or enhance your current mood.

Key Features:
- Real-time mood detection from selfies
- Animated mood ring visualization
- Personalized playlist generation
- Share your mood+music combination
- Daily mood tracking

Tech Stack:
- Frontend: HTML5, CSS3, JavaScript
- Face-api.js for emotion detection
- Spotify Web Playback SDK integration
- LocalStorage for mood history
